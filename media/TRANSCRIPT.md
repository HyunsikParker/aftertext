# Aftertext walkthrough

Silent screen recording with English captions.

0.0–8.1 s: Aftertext brings back teletext as a community bulletin you can edit, carry in a file and read offline.

8.6–16.7 s: Give a notice a page number. Type 201 to open the book swap. All notices in this example are fictional.

16.7–24.8 s: Reading view shows the full notice with ordinary text wrapping. It is also the default on a narrow phone.

24.9–33.9 s: Edit the current bulletin and watch its page preview. Each notice keeps its original words and spacing.

34.2–44.2 s: Long notices continue across subpages. The file preserves Unicode, newlines and spaces independently of the grid.

44.2–51.3 s: Turn the preview page to see the rest. Nothing is silently cut off to fit the screen.

51.4–59.5 s: Save the bulletin on this device. The reader and exported file now use the edited notice.

59.5–67.6 s: Export downloads the whole bulletin as a small JSON file. The byte count is measured from that file.

67.6–75.7 s: Open the exported file to restore the bulletin. The app does not upload it to a server.

75.8–85.8 s: Network disconnected, ordinary browser cache cleared, app reloaded. The saved bulletin still opens.

86.0–95.0 s: At phone width, reading view opens automatically. The same saved file stays available offline.

95.0–105.0 s: Built with Kiro CLI for the specification and initial validator, plus Codex for implementation and tests. Source and Kiro records accompany the demo.
